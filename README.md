# RedefineNCM

RedefineNCM is an Android music app that provides a smooth music playback experience.

## Features

- **Online streaming**

## Download

You can download the latest APK from
the [Releases](https://github.com/RedSTARO/RedefineNCM/releases) page.

## Build Instructions

### 1. Clone the Repository

```sh
git clone https://github.com/your-repo/RedefineNCM.git
cd RedefineNCM
```

### 2. Build the APK using Gradle

```sh
./gradlew assembleRelease
```
